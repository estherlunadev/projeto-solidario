# projeto-solidario
O Ponte Solidária é uma plataforma web desenvolvida com o objetivo de facilitar a organização e o gerenciamento de doações, conectando pessoas dispostas a ajudar com quem precisa de apoio. O projeto busca oferecer uma interface intuitiva, acessível e organizada, utilizando tecnologias como HTML, CSS e JavaScript para proporcionar uma experiência.
# Ponte Solidária

Projeto demonstrativo de uma plataforma de doações com 10 telas.

## Estrutura

ponte-solidaria/

## Como executar

1. Extraia a pasta `ponte-solidaria`.
2. Mantenha os nomes e a organização dos arquivos.
3. Abra `index.html` no navegador (ou use a extensão Live Server no VS Code).

## Tecnologias utilizadas

- HTML5: estrutura das dez telas e formulários.
- CSS3: identidade visual, layout responsivo, cartões, tabelas e tema claro/escuro.
- JavaScript: navegação entre telas, validação dos formulários, busca de itens, pré-visualização de imagens e atualização dos indicadores.
- LocalStorage: armazenamento local de cadastros, doações, agendamentos, sessão e preferência de tema.

## Observação

Este é um protótipo front-end. Os dados ficam armazenados no navegador utilizado. Para permitir acesso compartilhado entre diferentes usuários e dispositivos, será necessário implementar um backend e um banco de dados.
